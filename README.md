# Better Startpos (prototype, archived)

This was an early version of Better Startpos, written mostly with an AI
assistant. It was rejected from the Geode index under the
`reject-vibecoded` guideline, and that was fair.

I'm now rewriting the mod by hand while I learn C++. The rewrite lives in
[dwerked/better-startpos](https://github.com/dwerked/better-startpos) under the
new mod ID `dwerked.startpos-switcher`.

This repository is kept for reference only and gets no more updates.
